# なにたべ プライバシーポリシー

施行日: 2026年11月8日

なにたべ（以下「本アプリ」）は、今夜の献立の候補を3つ出し、家族の投票で決める iOS アプリです。
このポリシーは、本アプリが扱う情報と、その使いみちを説明します。

## 1. 本アプリが扱う情報

本アプリは、登録なしで使い始められます。氏名、メールアドレス、電話番号、位置情報、連絡先、写真は扱いません。
扱うのは、次の情報です。

- **匿名の ID**: 使い始めたときに、自動で発行されます。家庭のデータを、その家庭のメンバーだけに見せるために使います
- **表示名**: あなたが入力した名前です。家族の一覧と、投票した人の表示に使います。入力しなくても使えます
- **家庭のデータ**: 自分で追加したメニュー、その日の候補、投票、決まった献立、期間モード、投票の締め切りまでの時間
- **有料プランの状態**: 有料プランの期限と、購入した人の匿名の ID。有料の機能を、家庭のメンバー全員が使えるようにするために使います

## 2. 情報の保存先

- 上の情報は、Google が提供する Firebase（Firebase Authentication と Cloud Firestore）に保存します。家族の端末の間で、同じ候補と投票を見られるようにするためです。
  Firebase での情報の扱いは、[Google のプライバシーポリシー](https://policies.google.com/privacy)に従います。
- 通信がないときにも見られるように、同じ情報の写しを、あなたの端末にも保存します。
- 本アプリに同梱している定番のメニューは、アプリの中にあり、サーバーとはやり取りしません。

## 3. 情報が見える範囲

家庭のデータと表示名は、招待コードで同じ家庭に参加したメンバーに見えます。
ほかの家庭の利用者には見えません。

## 4. 購入の情報

有料プランの購入は、Apple の App 内課金で行います。支払いの処理は Apple が行い、本アプリは、クレジットカードなどの支払いの情報を受け取りません。
本アプリが扱うのは、有料プランが有効かどうかと、その期限だけです。

## 5. 情報の利用目的の限定

- 扱う情報は、献立を家族で決めるという本アプリの機能のためだけに使います。**広告やマーケティングには使いません。**
- 本アプリは、広告の SDK と、利用状況を解析する SDK を組み込んでいません。あなたを追跡しません。
- 法令にもとづく場合を除き、情報を第三者に提供しません。

## 6. 情報の削除

- 本アプリの「設定」›「データを削除する」から、あなたの情報を削除できます。削除されるのは、次の情報です。
  - あなたの表示名と、家庭とのつながり
  - 本アプリがあなたに割り当てた利用者の番号
  - あなただけが使っている家庭の場合は、あなたが追加したメニュー
- 家庭のほかのメンバーも使っているデータ（過去の献立と票数）は、ほかのメンバーのために残ります。あなたの票は、表示名と結び付かない形で残ります。
- あなただけが使っていた家庭の過去の献立は、だれも見られない状態でサーバーに残り、運営者が定期的に削除します。
- 本アプリを端末から削除すると、端末に保存した情報は削除されます。サーバーの情報は削除されないので、先に「データを削除する」を行ってください。
- 本アプリを削除したあとなど、アプリから削除できないときは、下のお問い合わせ先にお知らせください。
- 有料プランの購読は、データを削除しても自動では止まりません。iPhone の「設定」から解約してください。

## 7. 本アプリの位置づけ

本アプリは、献立を決める手助けをするものです。メニューに付いているラベル（高たんぱく、低カロリーなど）は目安で、栄養や健康についての正確さを保証するものではありません。
食事の制限やアレルギーがあるときは、ご自身で確かめてください。

## 8. 子どもの利用

本アプリは、13歳未満の子どもから、意図して情報を集めません。

## 9. ポリシーの変更

本アプリの情報の扱いを変えるときは、このポリシーを更新し、施行日を改めます。
